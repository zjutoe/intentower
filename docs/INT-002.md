## 1. 意图（草案，2 行）

一个恒温器维持温度在 0–100 之间：`warm` 使温度上升 1，`chill` 使温度下降 1，
两者都不得越界。第一版精化引入加热器，并必须证明它不违反温度边界。

## 2. 为什么需要第二个意图

`MODEL-001`（计数器）的 M0 含一条永久 `UNSUPPORTED` 义务（`m0::sub/act1/FIS`，
来自广义替换 `:|`），因此它的精化**结构上不可能**得到 PASS，无法用来检验
"自动精化能否闭合"。恒温器只用确定性赋值 `:=` 与 QF_LIA 可表达的算术，
且第一次自然的精化尝试会真实产生 2 条 `NOT_DISCHARGED` 反例
（`warm`/`chill` 守卫不够紧）——这是一个"有内容要修"的目标，不是送分题。
